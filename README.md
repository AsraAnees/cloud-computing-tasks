# DV1566 – Introduction to Cloud Computing

This repository contains laboratory work and the final project for **DV1566 – Introduction to Cloud Computing**.

## Laboratory Work

The laboratory work focuses on fundamental cloud-computing mechanisms and AWS resources, including:

- Creating and using virtual machines with Amazon EC2
- Configuring virtual storage and Virtual Private Clouds (VPCs)
- Setting up security groups, subnets, route tables, and internet gateways
- Monitoring CPU, disk, and network resource usage
- Performing load and communication testing between virtual machines

## Project – Scalable E-commerce Application on AWS

The project develops and deploys a scalable e-commerce website named **Refords** using **WordPress** and **WooCommerce** on AWS.

The project focuses on:

- Scalable cloud-based computation
- High availability and traffic management
- AWS EC2 deployment using Ubuntu
- MySQL for application data
- Elastic Load Balancing
- Performance testing and monitoring

The original proposal also considered AWS services such as Lightsail, CloudFront, Auto Scaling, and Lambda. The final implementation uses EC2, WordPress/WooCommerce, MySQL, and an Elastic Load Balancer.

# Cloud Computing

Coursework focused on practical cloud computing concepts and deployment using **Amazon Web Services (AWS)**.

## Lab 2 – AWS Virtual Machines and Monitoring

This lab focuses on creating and working with cloud infrastructure using **Amazon EC2**. It covers virtual machines, VPCs, subnets, security groups, routing, connectivity, resource monitoring, and performance testing. The work demonstrates how compute and networking resources are configured and observed in an AWS environment.

## Lab 3 – Scalable E-commerce Application on AWS

This project focuses on designing and deploying a scalable e-commerce environment using **WordPress**, **WooCommerce**, **AWS EC2**, **MySQL**, and an **Elastic Load Balancer**. It explores how cloud components can be combined to improve availability and distribute incoming traffic.

The project also considers deployment, scalability, monitoring, and performance, providing practical experience with hosting a web application using cloud infrastructure.

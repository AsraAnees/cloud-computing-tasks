# Cloud Computing

Coursework focused on cloud computing concepts and practical work using **Amazon Web Services (AWS)**.

## Lab 2 – AWS Virtual Machines and Monitoring

Practical work with AWS EC2 and cloud networking, including virtual machines, VPCs, subnets, security groups, routing, resource monitoring, and performance testing.

## Lab 3 – Scalable E-commerce Application on AWS

Design and implementation of a scalable e-commerce website using **WordPress**, **WooCommerce**, **AWS EC2**, **MySQL**, and an **Elastic Load Balancer**. The project explores scalability, availability, traffic management, deployment, and performance monitoring in a cloud environment.
